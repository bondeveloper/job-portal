# Triage labels

Standard five-role triage vocabulary:

| Label | Meaning |
|-------|---------|
| `needs-triage` | Issue submitted but not yet reviewed |
| `needs-info` | Waiting for additional information |
| `ready-for-agent` | Agent can start work immediately |
| `ready-for-human` | Requires human judgment or approval |
| `wontfix` | Not addressing this issue |

Add these to `.scratch/` issue files in front matter or checklist.
